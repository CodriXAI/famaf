Datos:

Esquema de paginación RISC-V con páginas de 4KiB de 
3 niveles (9,9,9,12) -> (44,12)

39 bits por dirección virtual, las cuales:
9 -> Nivel 2 (Page Directory Pointer Table)
9 -> Nivel 1 (Page Directories)
9 -> Nivel 0 (Page Tables)
12 -> Offset (Páginas)

El satp apunta a: 0x00000000FE0

Asumimos que si nos dan una dirección tipo:

0x1000 -> Es que hay 0s a la izquierda para completar los 
39 bits

Ejemplo:

0x1000 => 0x0000001000

(a): Traducir de virtual a física las direcciones:

Partimos que satp apunta a 0x00000000FE0 para buscar.

Dirección Virtual 0x0000:
    Pasamos a los 39 bits:
       000 | 0000 | 0000 | 0000 | 0000 | 0000 | 0000 | 0000 | 0000 | 0000
    Tomamos primeros 9 bits para Page Dir Pointer Table:
        000000000 = 0x000
    Tomamos segundos 9 bits para Page Dir:
        000000000 = 0x000
    Tomamos terceros 9 bits para Page Table:
        000000000 = 0x000
    Tomamos los últimos 12 bits para offset:
        000000000000 = 0x000
    
    Usamos el registro de paginación para hacer el page walk:

    0x00000000FE0 (PDPT):
        0x000 -> 0x00000000FEA -> Tiene todos los permisos 
    0x00000000FEA (PD):
        0x000 -> 0x000000AD0BE -> Tiene todos los permisos 
    0x000000AD0BE (PT):
        0x000 -> 0x0000000ABAD -> Es válida y solo escritura
    Concatenamos 0x0000000ABAD con el offset:
        0x0000000ABAD000 => 0xABAD000
    
    0x0000 a Física => 0xABAD000

Dirección virtual 0x1000:
    Pasamos a los 39 bits:
        000 | 0000 | 0000 | 0000 | 0000 | 0000 | 0001 | 0000 | 0000 | 0000

    Tomamos primeros 9 bits para Page Dir Pointer Table:
        000000000 = 0x000
    Tomamos segundos 9 bits para Page Dir:
        000000000 = 0x000
    Tomamos terceros 9 bits para Page Table:
        000000001 = 0x001
    Tomamos los últimos 12 bits para offset:
        000000000000 = 0x000
    
    Usamos el registro de paginación para hacer el page walk:

    0x00000000FE0 (PDPT):
        0x000 -> 0x00000000FEA -> Tiene todos los permisos 
    0x00000000FEA (PD):
        0x000 -> 0x000000AD0BE -> Tiene todos los permisos
