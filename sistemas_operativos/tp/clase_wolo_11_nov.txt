Ejercicio 10 (similar) Grafo de sincronización:

A -> B -> C
       -> D

El grafo nos indica que no hay dependencia

Para que se ejecute B debe terminar A y para que se ejecuten C y D debe terminar B

Se plantean los bloques (A,B,C,D)
	Y hay que implementarlo con semáforos:
	(Cuidado con los deadlocks)	

	S0 = 0 | S1 = 0 | S2 = 0 -> Indicando la inicialización.
 	
A		B		C		D
up(s0)		down(s0)	down(s1)	down(s2)
		up(s1)
		up(s2)

s0 gestiona B
s1 gestiona C
s2 gestiona D

Ejemplo mal:

A		B		C		D
up(s0)		down(s0)	down(s1)	down(s1)
		up(s1)		up(s1)

Esto está mal porque ocurre de manera secuencial (primero C, luego D) y no en paralelo.

Ejemplo bien optimizando semáforos:

A		B		C		D
up(s0)		down(s0)	down(s1)	down(s1)	
		up(s1)
		up(s1)

Termina A -> Habilita B con up(s0) -> B termina y se hace down(s0) -> Se habilitan
C y D con up(s1), up(s2) -> Terminan de ejecutarse C y D y se hace down(s1), down(s2)

Ejemplo más complejo:

A -> B -> C -> E
       -> D ->

Utilizando: s0 = 0 | s1 = 0 | s2 = 0

A		B		C		D		E
up(s0)		down(s0)	down(s1)	down(s1)	down(s2)
		up(s1)		up(s2)		up(s2)		down(s2)
