(a):

Lo que queremos mapear son 32MiB:
    
    Tenemos que estamos en un esquema ( 10, 10, 12 ) en i386.
    Luego 10 bits son para el PD, 10 bits son para PT, y 12 bits de offset.
    Por estándar de i386, cada Entrada (de PD y PT) ocupa 4 bytes.

    Primero, ¿Cuánta capacidad tiene una página?
        Si nos fijamos en el offset ocupa 12 bits. Si calculamos 2¹² = 4096 bytes
        Implica que cada página tiene una capacidad de 4KiB.
.
    Segundo, ¿Cuánto espacio EN MEMORIA ocupa 1 Page Table?
        Si nos fijamos, tenemos que para las PT, tenemos 10 bits reservados.
        Luego, cada page table tiene 2¹⁰ = 1024 entradas y por estándar de i386,
        4 bytes por entrada => 1024 * 4 bytes => 4KiB por Page Table (Espacio en Memoria).

    Tercero, ¿Cuánta capacidad de MAPEO tiene 1 Page Table?
        Como cada PT apunta a 1024 páginas (una página por entrada). Tenemos que:
        4Kib * 1024 = 2¹² * 2¹⁰ = 2²² = 4MiB de capacidad de Mapeo por Page Table  
    
    Cuarto, ¿Cuántas PT's necesitaríamos para mapear 32MiB?
        Si cada page table puede mapear hasta 4MiB, entonces necesitamos 
        8 pages tables para mapear las 32MiB.
    
    Quinto, ¿Cuánto espacio EN MEMORIA ocupa el Page Directory?
        Tenemos 10 bits reservados para el Page Directory, y cada entrada 
        por estandar ocupa 4 bytes, 4 * 1024 = 4KiB de espacio en memoria por 
        parte del Page Directory 

    Sexto, ¿Cuánto espacio EN MEMORIA ocupa TODO (Directorio y Tabla de 
    páginas)?
        Tenemos 1 PD (4KiB) + 8 PT (32KiB) = 36KiB para mapear 32MiB 

    Séptimo, Conclusiones:
        NO Confundir ESPACIO EN MEMORIA con CAPACIDAD DE MAPEO:
            El espacio es lo que ocupa la estructura como tal 
            El mapeo es cuanto espacio puede relacionar con los punteros 
        
        Ejemplo:
            El PD ocupa en memoria 4KiB, sin embargo tiene una capacidad de 
            mapeo de 4GiB
            1024 entradas apuntando a los 4MiB que mapea cada page table 
            = 2¹⁰ * 2²² = 2³² = 4GiB

    1 PD + 1024 PT que dieron de resultado: 4KiB + 4MiB de Tamaño

    Si fuese para un esquema de un solo nivel, tendríamos a disposición una PT que por estándar de 
    i386 cada entrada de la misma ocupa 4 bytes. Para las 4GiB que queremos mapear deberiamos tener 
    en cuenta que:
        * Las páginas siguen siendo de 4KiB eso quiere decir que el offset sigue siendo 12 bits 
        * Como siguen siendo direcciones de 32 bits tenemos que un nivel sería: 32 - 12 = 20 bits para 
        la PT. Por ende tendríamos 2²⁰ = 4MiB de espacio reservado para la PT, es decir: 1.048.576 entradas 
        (Muchas páginas alv :p)

        * Luego la capacidad de mapeo de la Page Table con esos 4Mib sería de:
        1.048.576 * 4KiB (Cant de entradas * El espacio de las páginas) = 2²⁰ * 2¹² = 2³² = 4GiB
