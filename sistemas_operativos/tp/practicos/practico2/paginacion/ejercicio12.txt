=== EJERCICIO 12 - PRACTICO 2 S.O ===

Dado un tamaño de página de 4 KiB = 2¹² = 4096 bytes y la tabla
de paginado de la Fig. 1.

(a) ¿Cuántos bits de direccionamiento hay para cada espacio?

(b) Determine las direcciones fı́sicas a partir de las virtuales: 39424, 12416,
26112, 63008, 21760, 32512, 43008, 36096, 7424, 4032.

(c) Determine el mapeo inverso, o sea las direcciones virtuales a partir de las
direcciones fı́sicas: 16385, 4321.

Donde:
V = Virtual / F = Física / Validez (1 = Es válida, 0 = No es valida => Page Fault)

En detalle:
    *Tenemos 16 entradas (páginas) de la 0 a la 15, cada una con sus datos.
    *El esquema de paginación está dividido en páginas de 4KiB => 12 bits de offset
    *Dichos 12 bits menos significativossirven para el desplazamiento, tanto para las páginas virtuales 
    como los marcos físicos.
    *Para el espacio virtual, se requiere saber el VPN (Virtual Page Number), representado según la cantidad 
    de entradas (en este caso son 16 páginas, que se pueden representar con 4 bits)
    *Para los marcos físicos, podemos ver en tabla que se representan con 3 bits (2³ marcos, 8 marcos)

(a): 
    Para el espacio de paginas virtuales, se requieren 4 bits de VPN + 12 bits de offset = 16 bits
    Para el espacio de los marcos físicos, se requieren 3 bits de marco + 12 bits de offset = 15 bits 

(b):

    Para pasar de virtual a física:
        Primero para saber la dirección virtual:
        VPN = (VA / size_page) PARTE ENTERA
        Offset = VA % size_page RESIDUO

        Y de ahi traducirlo a física (en este caso en tabla):
            (Marco Fisico * size_page) + offset 
    
    Para saber el residuo:
        Algoritmo de la división:
            Dividendo = (Divisor * Cociente) + Resto
            {Restamos Resto a ambos lados}
            Dividendo - Resto = (Divisor * Cociente)
            {Restamos Dividendo a ambos lados}
            - Resto = (Divisor * Cociente) - Dividendo
            {Multiplicamos por (-1) en ambos lados}
            Resto = -(Divisor * Cociente) + Dividendo
            {Conmutatividad}
            Resto = Dividendo - (Divisor * Cociente)
