SIGNIFICADO DE LAS POLÍTICAS:

STCF (Shortest Time to Completion First):
    En cada momento, el scheduler selecciona el proceso con menor tiempo restante entre
    los que hayan llegado

    Si llega un proceso nuevo con menor tiempo restante al que está ejecutándose
    el proceso en ejecución se "preempa" (quita cpu) y pasa a Ready y ejecuta el
    nuevo.


RR (Round Robin):
    
    El objetivo de esta política es garantizar la justicia (fairness).
    Los procesos se almacenan en una cola circular FIFO
    Luego se comienza a ejecutar el primer proceso en la cola, ¿bajo qué contexto?
    Para garantizar la justicia, se utiliza un parámetro de medida de tiempo
    llamado "Quantum", en donde:
        Si el proceso demora menos de lo indicado en el quantum, el scheduler le brinda
        el cpu al siguiente proceso de la cola.
        
        Si el proceso está demorando más que el quantum, el scheduler inmediatamente
        le quita la cpu al proceso y le brinda al siguiente sin dejar que dicho proceso
        finalice. La cuestión es que cada proceso tendrá como mucho la misma cantidad de 
        tiempo y si no lo respetan, el scheduler lo fuerza directamente

    T:5 -> Termina de ejecutarse el T-cpuCNow de C 
            -> Sigue con A | Procesos en Running: A, Procesos en Ready: Nothing
    T:8 -> Termina de ejecutarse el T-cpuANow de A

LÍNEA DE TIEMPO RR CON QUANTUM = 2:
